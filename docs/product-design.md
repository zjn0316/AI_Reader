# 产品设计文档 — 马克阅读（AI Reader）

## 1. 目标

做一个本地优先、打开即读的电子书阅读器。MVP 阶段以最低成本验证「导入 → 阅读 → 调节字号」的主流程。

## 2. MVP 功能边界

**包含：**

| 功能 | 说明 |
| --- | --- |
| 导入 TXT | 点击选择本地 `.txt` 文件，读取其文本内容 |
| 纵向滚动阅读 | 将文本按段落展示，从上到下滚动阅读 |
| 字号可调 | 通过 A− / A+ 增大/减小正文文字大小 |
| 字号持久化 | 字号写入浏览器 `localStorage`，下次打开保持 |

**排除（后续迭代）：**

- EPUB / PDF 等格式支持
- 目录（TOC）导航
- 书签与阅读进度记录
- 深色主题
- 云端同步 / 多端登录

## 3. 约束与边界

- 仅支持 `.txt`，且只做文本的展示，不做样式解析。
- 纯前端实现，不依赖后端服务，无账号体系。
- 数据仅存于浏览器本地，不做上传。

## 4. 验收标准

1. 选择一个 `.txt` 文件后能正确显示其内容。
2. 选择非 `.txt` 文件时给出明确的错误提示。
3. A+ / A− 能实时调整字号，且刷新后字号保持不变。
4. 空内容或未打开书籍时展示空态占位。
